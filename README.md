# Rounak Gupta — Portfolio

A cinematic, responsive personal portfolio built with React, TypeScript, Vite, GSAP, and ScrollTrigger.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Portrait

The portrait is served from `public/assets/rounak.jpg`. If that file is unavailable, the portfolio shows a designed placeholder instead.

## Project repositories

The portfolio links to the public CPU Scheduling Simulator, Rounak Management Software, and cosmetics-store repositories associated with the `rounakg834-droid` GitHub account. The Smart Traffic / Parking project is shown without a repository link because a matching public repository was not available.
